# 🔐 Technical Treasure Hunt

An interactive **Technical Treasure Hunt** developed for **Engineering Day 2026**.

Participants solve technical questions, follow clues, and unlock the next stage step-by-step until they reach the final treasure.

### Features

* Technical questions with clues
* Progressive stage unlocking
* Hints and scoring
* Countdown timer
* Fully offline
* Responsive web interface

### Tech Stack

**HTML • CSS • JavaScript • LocalStorage**

> **Think. Solve. Decode. Unlock. 🏆**
